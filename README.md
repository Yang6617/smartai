# 灵析AI - 智能知识库问答系统

灵析AI是一个基于RAG（检索增强生成）技术的智能知识库问答系统，支持文档上传、智能解析、向量存储和基于知识库的问答功能。系统包含完整的前后端架构，支持微信小程序界面交互。

## 项目概述

灵析AI系统旨在帮助用户快速构建个人或团队专属的知识库，通过上传文档实现智能化问答。系统采用先进的RAG技术，能够准确理解和回答基于上传文档内容的问题，并提供引用来源。

### 核心功能
- 📚 **多格式文档支持**：支持PDF、Word、Markdown、TXT等多种文档格式
- 🔍 **智能文档解析**：自动解析文档结构，提取标题、段落、列表等内容
- 🧠 **RAG检索增强**：结合向量检索和大语言模型生成准确答案
- 💬 **智能问答**：基于知识库内容的高质量问答服务
- 📱 **微信小程序**：友好的用户界面，支持移动端访问
- 👥 **团队协作**：支持群组管理和知识库共享
- ⭐ **收藏分享**：支持收藏有价值的问答记录并分享给团队

### 核心模块

#### 1. 文档预处理器 (doc_preprocessor)
- **格式路由分发**：智能识别文件类型并选择最优解析策略
- **文档解析集群**：支持多种格式的文档解析，输出标准化Element对象
- **文本清洗模块**：清理文档内容，修复OCR错误，标准化格式
- **智能分块引擎**：基于语义边界的自适应分块，保持上下文连续性

#### 2. RAG推理引擎 (rag_engine)
- **查询理解**：意图分类、查询重写、上下文管理
- **混合检索**：向量检索 + 关键词检索 + 结果融合重排
- **Prompt工程**：智能模板选择、上下文拼装、安全约束
- **LLM客户端**：支持多种大模型接口，流式响应处理

#### 3. 向量数据库引擎 (vector_engine)
- **向量数据库代理**：统一接口支持多种向量数据库（ChromaDB等）
- **嵌入模型加载器**：动态加载BGE-M3等嵌入模型，支持GPU加速
- **批量处理器**：高效处理文档向量化和存储

## 快速开始

### 环境准备
```bash
# 1. 安装Python依赖
pip install -r backend/fastapi_project/requirements.txt

# 2. 下载嵌入模型（如BGE-M3）
# 将模型文件放置到 model/ 目录

# 3. 初始化向量数据库
python core/vector_engine/scripts/init_chromadb_local.py

# 4. 启动后端服务
cd backend/fastapi_project/
python run_backend.py
```

### 前端使用
1. 使用微信开发者工具打开 `frontend/lingxi` 目录
2. 配置服务器地址为 `http://localhost:8000`（或实际后端地址）
3. 编译运行小程序

### API接口使用
```python
from core.service_interface import upload_file_interface, ask_question_interface

# 上传文档到知识库
result = upload_file_interface(
    file_path="./manual.pdf",
    user_id="user_123",
    knowledge_base_id="kb_company_docs"
)

# 基于知识库提问
response = ask_question_interface(
    question="公司政策是什么？",
    user_id="user_123",
    knowledge_base_id="kb_company_docs"
)
```

## 快速开始

### 1. 上传文档
```python
from core.service_interface import upload_file_interface

result = upload_file_interface(
    file_path="your_document.pdf",
    user_id="user_12345",
    knowledge_base_id="kb_company_policies",
    file_name="employee_handbook.pdf",
    custom_metadata={
        "department": "HR",
        "version": "2024",
        "tags": ["policy", "handbook", "employee"]
    }
)
```

### 2. 进行提问
```python
from core.service_interface import ask_question_interface

response = ask_question_interface(
    question="公司请假政策是什么？",
    user_id="user_12345",
    knowledge_base_id="kb_company_policies",
    top_k=5,  # 检索前5个相关片段
    temperature=0.3  # 更准确的回答
)
print(response['answer'])
print(response['citations'])  # 查看引用来源
```

### 限制与注意事项

#### 文档处理限制
- 复杂表格和图表的解析可能不完整
- 某些特殊格式的文档可能无法正确解析
- 文档过大时处理时间较长

#### 问答限制
- 文档切分可能导致上下文关联性降低
- 跨文档的复杂推理能力有限
- 对于未在知识库中的问题无法回答

#### 性能考虑
- 首次查询可能较慢（向量索引加载）
- 大量文档的知识库响应时间可能较长
- 复杂问题需要更多处理时间

## 最佳实践

### 上传文档建议
1. **保持结构清晰**：使用清晰的标题层级和段落结构
2. **避免过长段落**：合理分段，便于理解和检索
3. **使用一致术语**：保持术语和表述的一致性
4. **添加元数据**：使用自定义元数据增强可检索性
5. **定期更新**：及时更新过时文档，保持知识库时效性

### 提问技巧
1. **具体明确**：使用清晰、具体的问题
2. **包含关键词**：在问题中包含文档中的关键词
3. **上下文补充**：必要时提供背景信息
4. **分步提问**：复杂问题可拆分为多个简单问题
5. **引用验证**：检查回答中的引用来源以确认准确性

### 知识库管理
1. **分类组织**：按主题或部门创建不同的知识库
2. **标签管理**：使用标签对文档进行分类管理
3. **定期维护**：清理过时文档，更新重要信息
4. **权限设置**：合理设置知识库访问权限
